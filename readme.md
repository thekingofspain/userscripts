# userscripts

Tampermonkey userscripts. Install via the raw GitHub URLs below.

| Script | Description | Install |
| --- | --- | --- |
| Ask Gemini | Table and message width fixes for Gemini. | [install](https://raw.githubusercontent.com/thekingofspain/userscripts/main/ask-gemini.user.js) |
| Google Docs Annoyance Helper | Auto-dismisses paste nags and removes account modals on Google Docs/Sheets/Slides. | [install](https://raw.githubusercontent.com/thekingofspain/userscripts/main/google-docs-annoyance-helper.user.js) |
| Make All Textareas Resizable | Forces all textareas to be freely resizable. | [install](https://raw.githubusercontent.com/thekingofspain/userscripts/main/make-all-textareas-resizable.user.js) |
| Qwen Chat - Unset Max-Width | Removes the max-width restriction on Qwen chat messages. | [install](https://raw.githubusercontent.com/thekingofspain/userscripts/main/qwen-chat-unset-max-width.user.js) |

## Sync

Tampermonkey Dashboard → Settings → Config Mode `Beginner`/`Advanced` → Script Sync → `Browser Sync` → Enable → Save.
Scripts carry `@downloadURL` raw-GitHub URLs, so the repo stays source of truth across browsers.
